# 🎵 Lyric Printer CLI

A fun Python command-line program that prints song lyrics with a smooth typewriter effect .... inspired by a TikTok project.
blah blah  blah 
## ✨ Features
- **Typewriter Effect** – Prints text character-by-character in real-time.
- **Custom Timing** – Adjustable delays between lines for dramatic effect.
- **Easy to Modify** – Replace lyrics with your own text or quotes.
- **Pure Python** – No extra libraries needed.

## 🚀 How to Run
1. Clone the repo:
   ```bash
   git clone https://github.com/Yuyi5la/lyric-printer-cli.git
   cd lyric-printer-cli
2. Run the script:
  ```bash
python lyrics.py
 ```
🛠 How to Customize

Open lyrics.py

Edit the lyrics list with your own lines and delays.
Example:
  ```bash
("Hello world!", 1.0)
 ```
First value is the text, second is the pause before the next line.
